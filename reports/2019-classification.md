## 유형별 권장 학습 순서

- 공기조화: 상태량·현열과 잠열 → 1회 1번 선도 → 1회 9번 부하 → 3회 3번 겨울철 계산 → 2회 3번 냉각감습. 서술은 2회 2번으로 별도 복습합니다.
- 냉동사이클: 3회 7번 이론 히트펌프 → 2회 9번 과냉각 → 1회 2번 상태점 → 3회 5번·1회 7번 열교환 및 혼합 → 1회 2번 순환비 → 2회 12번 2단 압축기. 서술은 3회 2번으로 별도 복습합니다.
- 냉동부하: 3회 13번 기기부하 → 3회 10번 제빙 → 2회 1번 냉장고 열평형.
- 열전달·벽체: 3회 11번 열저항 → 2회 6번 표면온도·결로 → 2회 7번 노벽 두께.
- 열교환기: 2회 4번 열평형 → 1회 3번 열관류율 → 1회 10번 전열면적·코일 설계 → 1회 12번 온수코일 종합 설계.
- 온수난방·펌프: 1회 6번 순환량·용량 → 1회 8번 관경 → 2회 5번 급수펌프. 1회 15번 배관도와 2회 8번 인젝터 서술을 따로 복습합니다.
- 송풍기·덕트: 1회 13번 동력 → 3회 9번 상사법칙 → 3회 1번 결로 → 2회 11번 덕트 → 3회 12번 공조·덕트 종합. 1회 14번 취출구 용어는 서술로 따로 공부합니다.
- 냉각탑: 3회 6번 온도와 효율 계산 → 1회 4번 개념·설치 서술.
- 냉방부하: 1회 11번 시간별 취득열 → 2회 10번 최대부하 → 3회 8번 최상층 종합부하.
- 냉동장치 도면: 3회 14번 흡입배관 → 1회 5번 핫가스제상 → 2회 14번 냉매액 순환식.
- 전기제어·적산: 2회 13번 회로 판독과 3회 4번 배관 내역서는 별도 유형으로 학습합니다.
