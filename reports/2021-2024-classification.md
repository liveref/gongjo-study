# 2021~2024 추가 수록 검토

168문제 / 182개 학습 항목 / 원본 사진 116장.

기존 사이트의 범주와 기초·응용·종합 난이도 체계를 사용했습니다. 원리 난이도 1~2는 기초, 3은 응용, 4~5는 종합으로 매핑했습니다. 이 등급은 학습용 판단입니다.

계산기를 사용하는 경우 식을 세운 뒤의 계산과 원리 해석의 난이도 차이를 확인할 수 있도록 원리·계산 난이도 원자료도 데이터에 보존했습니다. 기존 화면에는 기존 3단계 등급으로 표시합니다.

선도에서 값을 읽어 계산하는 것만 요구하면 계산으로 분류했습니다. 실제 선도 작성·배관 연결·회로 해석 요구는 그림·선도로 분류하며, 설명 요구가 함께 있으면 서술 항목을 추가했습니다.

문제 요약은 제목과 원문에서 확인한 핵심을 사용합니다. 표에 없는 수치·배점·정답·출제확률·풀이시간은 추가하지 않았습니다. 사진은 인접 문제나 풀이를 포함하는 두 페이지 펼침 사진이며, 문제·조건표·풀이가 이어지는 사진 범위를 확인하여 연결했습니다.
