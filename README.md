# 차곡차곡 공조 · 나의 기출문제은행

공조냉동기계기사 실기 기출 314문제, 기존 기록 항목 342개를 수록한 학습 사이트입니다.

현재 운영 주소: https://gongjo-study-2018-sj.lakefeline.chatgpt.site/

## 수록 기능

- PDF 기준 유형 및 선수학습 순서
- 연도·회차·문제 번호와 교재 첫 페이지
- 계산·서술·도면 구분과 원본 교재 사진
- 회독 별표, 숨기기, 오답노트 및 옅은 붉은 카드 표시
- 기존 Sites 환경에서의 로그인 및 기기 간 학습 기록 동기화

## 저장소 이전

기존 Sites 버전 12의 소스 스냅샷을 가져왔습니다. 교재 사진과 문제 데이터는 원본 파일을 그대로 보존합니다. 개인정보·학습 기록 데이터베이스·비밀키·로컬 환경 파일은 포함하지 않습니다. 교재 사진이 포함되어 저장소를 비공개로 유지합니다.

독립된 GitHub 저장소에서도 검증할 수 있도록 과거 대조 기준 파일을 tests/baseline에 보존했습니다. 테스트가 이전 비공개 Git 이력에 의존하지 않습니다.

## 실행과 검증

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm run dev
node --test tests/catalog.test.mjs tests/curriculum.test.mjs tests/store.test.mjs tests/sync.test.mjs
npm run build
```

## 실제 배포 시 필요한 작업

이 저장소는 서버를 사용하는 Cloudflare Worker/Vinext 앱이며 GitHub Pages에 그대로 배포할 수 없습니다. GitHub 저장소 업로드와 실제 사이트 배포는 별개입니다.

현재 인증은 Sites가 주입하는 검증된 사용자 헤더와 /signin-with-chatgpt 경로에 의존합니다. 별도 호스팅에 연결할 때는 새 호스팅에서 지원하는 인증을 구현하고, 외부 요청이 사용자 헤더를 위조할 수 없도록 해야 합니다. 단순 헤더 복사나 인증 우회로 대체하면 안 됩니다.

학습 기록은 기존 서비스의 Cloudflare D1에 남아 있습니다. 독립 호스팅에는 D1 연결과 인증 사용자 매핑 및 기록 이전 절차가 필요합니다. .openai/hosting.json의 기존 프로젝트 ID만으로 새 호스팅이 그 데이터베이스를 사용할 수는 없습니다.

실제 호스팅·인증·데이터 이전을 완료하기 전까지 기존 사이트를 계속 사용하세요. 이 저장소 업로드는 기존 사이트나 저장된 학습 기록을 변경하지 않습니다.
